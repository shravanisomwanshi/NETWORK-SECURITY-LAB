7. CONFIGURE Fa0/1 AND Fa0/2 AS TRUNK
------------------------------------------------------------

Configuration:
Switch1

Interfaces:

Fa0/1
Fa0/2

Command:

interface range fa0/1-2
switchport mode trunk
exit

Purpose:
Configures Fa0/1 and Fa0/2 as trunk interfaces.

These interfaces connect Switch1 with Switch2
and carry traffic belonging to multiple VLANs.


------------------------------------------------------------
8. VERIFY TRUNK CONFIGURATION
------------------------------------------------------------

Configuration:
Switch1

Command:

do show interfaces trunk

Purpose:
Verifies whether Fa0/1 and Fa0/2 are operating
as trunk ports.

Expected:

Fa0/1 → trunking
Fa0/2 → trunking


------------------------------------------------------------

Switch1

Fa0/2

trunk interfaces.

============================================================
              NATIVE VLAN MISMATCH
============================================================

If the following error appears:

%CDP-4-NATIVE_VLAN_MISMATCH

it means that both ends of the trunk are configured
with different Native VLANs.

Check using:

show interfaces trunk


Correct configuration on BOTH switches:

interface range fa0/1-2
switchport trunk native vlan 99
exit


Both sides of every trunk link must have the same
Native VLAN.
