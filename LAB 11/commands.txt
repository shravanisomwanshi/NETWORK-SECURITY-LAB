MANUAL "ON" ETHERCHANNEL CONFIGURATION
================================================

Topology:
S1 <--> S2 : Fa0/1-3  -> Port-Channel 2
S1 <--> S3 : S1 Fa0/4-6 + S3 Fa0/1-3 -> Port-Channel 1
S2 <--> S3 : Fa0/4-6  -> Port-Channel 3


================================================
SWITCH 1 (S1)
================================================

# Channel Group 1: S1 Fa0/4-6
# Connects S1 to S3

enable
configure terminal
interface range fa0/4-6
channel-group 1 mode on
exit

interface port-channel 1
switchport mode trunk
exit

do show etherchannel
end

# Connects S1 to S2
